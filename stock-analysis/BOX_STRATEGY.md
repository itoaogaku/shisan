# ボックス相場戦略：ルールと購入までの流れ

サポートライン（下限）とレジスタンスライン（上限）の間を、3か月〜1年の周期で行き来している大型株を、**下限付近で買い、上限付近で売る**戦略です（2026-10-12 作成）。
売買を推奨するものではなく、判断材料をそろえるための手順です。

## 1. ルール

### ① ボックス相場の判定（`screen_box.py`）

直近を終点とする1〜3年の期間（250〜735営業日）で、次の条件をすべて満たす最も長い期間を「ボックス」とします。

| 項目 | 条件 |
|---|---|
| サポート・レジスタンス | その期間の終値の5パーセンタイル（下限）と95パーセンタイル（上限） |
| ボックス幅 | 15〜70% |
| 往復の回数 | 下側1/4と上側1/4に、それぞれ2回以上交互に到達 |
| 周期 | 1往復が平均60〜250営業日（約3か月〜1年） |
| 横ばいであること | 期間の前半1/3と後半1/3の平均の差が、ボックス幅の40%以内 |
| 山と谷のそろい方 | 各到達時の高値・安値のばらつき（変動係数）が6%以内 |
| 現在値 | サポート×0.95〜レジスタンス×1.05 の範囲 |
| 除外 | 1日で±45%超動いた銘柄（株式分割の調整漏れの疑い） |

### ② 対象銘柄（`screen_box_timing.py` の既定値）

- 60日平均売買代金が20億円以上（大型株）
- 上側・下側の到達がそれぞれ3回以上
- ボックスの開始が1年半以上前

### ③ 買い時点（100点満点）

| 要素 | 配点 | 内容 |
|---|---|---|
| ボックス内の位置 | 50点 | サポートにあると50点、ボックスの70%の位置で0点（直線で減点） |
| 下げ止まりの兆し | 30点 | 次の3つを各10点：終値が5日線より上／5日線が上向き／直近5日で、その前15日の安値を更新していない |
| 上値の余地 | 20点 | レジスタンスまでの上昇余地が15%以上で20点、10〜15%で12点、5〜10%で5点、5%未満で0点 |
| 増収の加点 | +5点 | 直近四半期の売上が前年同期より多い（上限100点） |

### ④ 業績チェック（どれかに当てはまれば、点数に関係なく「見送り（業績）」）

1. 直近四半期の営業利益が赤字、または前年同期比で−10%を超える減益
2. 今期の会社予想で、営業利益が前期比−10%を超える減益
3. 予想PERが40倍以上、または今期が赤字予想
4. 最新の四半期決算が出ていない（四半期末から150日超。決算発表の遅れの疑い）

業績データは株探の決算ページから取り、取れないときはIRBankの四半期実績を使います。
過去検証（`backtest_box.py`、2024-10〜2026-07の月初15時点、下限シグナル298件）では、1で外れた銘柄の3か月後の成績は次のとおりでした。

- ボックスを下に抜けた割合：42%（残った銘柄は25%）
- TOPIX比で−10%以下になった割合：34%（残った銘柄は21%）

一方、平均の超過リターンはほとんど変わりませんでした。このチェックは「大きな失敗を減らす」ためのもので、もうけを増やすものではありません。2〜4は、当時の会社予想が手元にないため検証していません。

### ⑤ 区分

| 区分 | 条件 | 扱い |
|---|---|---|
| 対象 | ボックス内にあり、業績チェックを通過 | 買い時点の高い順に検討する |
| 決算待ち | 次回決算まで14日以内 | 決算後に再判定する |
| 下抜け中 | ボックス内位置が−3%未満 | サポートの上に戻るまで待つ |
| 上抜け中 | ボックス内位置が100%超 | ボックス戦略の買い場ではない |
| 見送り（業績） | 業績チェックに不合格 | 買わない |

## 2. 購入までの流れ

| 手順 | 作業 | コマンド・担当 |
|---|---|---|
| 1 | 銘柄一覧を更新する（月1回程度） | `python3 stock-analysis/screen_universe.py` |
| 2 | プライム市場の全銘柄の日足（3年分）を取得する（約30分） | `python3 stock-analysis/fetch_box_prices.py stock-analysis/screening/universe.csv <日足フォルダ>` |
| 3 | ボックス相場を判定する | `python3 stock-analysis/screen_box.py <日足フォルダ> stock-analysis/screening/universe.csv stock-analysis/screening/box_<日付>.csv` |
| 4 | 買い時点と業績チェックで並べる | `python3 stock-analysis/screen_box_timing.py stock-analysis/screening/box_<日付>.csv <日足フォルダ> stock-analysis/screening/box_timing_<日付>.csv` |
| 5 | 上位の銘柄を確認する：業績が「不明」の銘柄の手確認、直近のニュース・適時開示、次回決算日、チャートの目視確認 | Claude |
| 6 | 買う前に決める：売りの目安、撤退の目安、決算をまたぐか、株数 | 本人 |
| 7 | 注文する：寄り付きの値段を確認し、指値で注文する | 本人 |
| 8 | 約定したら、値段・株数・日付を記録する | 本人 → Claude |

日足は約90MBあるのでコミットしません（`data/prices/` と同じ扱い）。

## 3. 買ったあと

| 状況 | 目安 | 対応 |
|---|---|---|
| 上限に近づいた | ボックス内位置が85〜100% | 売りを検討する |
| 上限を超えた | 位置100%超 | ボックス戦略としてはいったん終わり。続けて持つかは、別の判断として考える |
| 下限を割った | 終値がサポート×0.97を下回った | ボックスの前提が崩れた。撤退を検討する |
| 決算が出た | 決算発表の翌日 | 手順4を再実行して業績チェックをやり直す。「見送り（業績）」になったら撤退を検討する |

撤退の目安を機械的に守るかどうかは、買う前に決めておきます。なお、別の方式（強い株を選ぶ方式）の検証では、損切りルールで成績が下がりました。ボックス戦略の損切りは、まだ検証していません。
