# 新方式の過去検証（2026-10-06）

> 新方式（強い株100から買い時点で20を選ぶ）を過去の時点で再現し、その後の値動きを調べた。売買の推奨ではない。
> スクリプト：`backtest_strength.py`（2時点の詳細）、5年分の日足は `fetch_long.py` で取得。

## 再現できたこと・できないこと

- 再現した：株価の強さ（6か月の上昇率・52週高値への近さ）、200日線の上、買い時点、過熱の安全柵（200日線+60%超・RSI80以上）。
- 再現できない：業績（当時の会社予想がない）による選別、割高（PER40倍以上）の除外、TOB・売出し・不正の開示チェック、決算前の「待ち」。強い株スコアは強さ点だけで代用した。
- 対象は「いま上場している銘柄」だけ。途中で上場廃止になった銘柄は含まれないため、成績はやや良く出やすい。

## 3. 結論

1. **新方式には小さいが一貫した優位があった**：基準を決めた期間の外でも、6か月後に市場平均を平均+3.0%上回り、7割の時点で市場に勝った。ただし3か月後の差は+0.5%とわずかで、以前の検証の「+7.0%」は期間の偏りで大きく出ていた。
2. **「強さ上位20をそのまま」は市場に負けた**：強い株を買い時点で選び直す工程（ユーザー提案）が、成績の差を生んでいる。
3. **安全柵（過熱の除外）は妥当**：広い期間では、過熱銘柄は市場を下回った（6か月後 −2.4%）。2025年10月のように過熱株がさらに上がる時期もあるが、平均では外す方が良かった。
4. **下落相場には弱い**：市場が下げた時点では市場平均を2.4%下回った。2024年10月はこの例で、その後の下落（2025年4月の急落を含む）で20銘柄中15銘柄が6か月後に下がった。
5. **市場全体の確認が役に立つ可能性**：TOPIXが200日線の下にある時期は、新方式の優位がなくなった（市場比−1.0%）。ただし時点数が11と少なく、2024年10月はTOPIXが200日線の上だったため、この確認だけでは防げなかった。
6. **業績の部分は未検証**：実際の新方式は業績でも選別しているが、当時の会社予想のデータがないため、効果は確かめられていない。

## 4. 売りルールと買い方の比較（追加検証）

新方式の20銘柄を等金額で持った場合。期間は2022-10〜2025-09の2週間おき72時点（ルール作りに使っていない期間）。売りは翌営業日の始値、売った後は現金。スクリプト：`backtest_rules.py`・`backtest_tranche.py`・`backtest_stop.py`。

| 方法 | 6か月後の平均 | 最悪の時点 | 備考 |
|---|---|---|---|
| 持ち続け（売りルールなし） | +10.8% | −9.3% | マイナス8/72 |
| 200日線を割ったら売る | +7.2% | −18.0% | 平均10銘柄を売る。売った後の反発を取り逃がす |
| 買値−10%で売る | +6.2% | −14.5% | |
| 高値から−15%で売る | +5.1% | −17.9% | |
| 50日線・25日線・ATRで売る | +0.7〜+1.8% | −9〜−13% | ほぼ全銘柄を売ってしまう |
| 月1回の入れ替え | +10.9% | −16.5% | マイナス14/72 |
| 入れ替え＋TOPIXが200日線の下なら現金 | +8.3% | −23.3% | 底で売ってしまう |
| **3回に分けて買う（月1回×3回、各回6か月保有）** | **+11.0%** | **−5.3%** | −5%以下は1/72（一度に全額は5/72） |

400万円での例（6か月保有）：

| 開始 | 一度に全額 | 200日線で売る | 3回に分けて買う |
|---|---|---|---|
| 2024-10-07 | 357.2万円 | 366.2万円 | 403.1万円 |
| 2025-10-06 | 517.3万円 | 518.4万円 | 545.0万円 |

「3回に分けて買う」の最後の回は開始から2か月後に買い、その6か月後（開始から8か月後）に評価するため、比べる期間が少し長い点に注意。2024年の例では、2025年4月の急落後に回復した時期まで含まれている。

**結論**：この期間では、個別株の売りルール（損切り）はどれも成績を下げた。強い株は一時的に下げてから戻ることが多く、売った後の反発を取り逃がすため。悪い時期に一度に買ってしまう危険を減らすには、売りルールより「買う時期を分ける」方が効果的だった。
